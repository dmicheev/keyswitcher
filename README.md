# keyswitcher (smartswitcher)

Smart Switcher для macOS (на Rust): раскладка (EN/RU) под активное окно + автопереключение по ходу печати (Punto-стиль).

Программа запоминает, какая раскладка использовалась в каждом окне, и восстанавливает её при возврате в окно; новым окнам применяется раскладка по умолчанию. Ручное переключение не «борется» с программой — оно запоминается для текущего окна.

Дополнительно работает режим печати: по потоку физических клавиш программа определяет, на каком языке вы собираетесь набрать слово, и при уверенном определении **переключает раскладку и исправляет уже набранный «неправильный» префикс** (backspace × k + ввод правильных символов) — как Punto Switcher. Отдельная горячая клавиша конвертирует последнее слово в другую раскладку.

## Возможности

- **Иконка в меню-баре** — показывает текущую раскладку (EN/RU); клик открывает меню:
  быстрое переключение, настройки, открытие `config.txt` и журнала, выход.
- **Диалог настроек** — автокоррекция, автопереключение по печати, ретро-фикс,
  спеллчек-подсказки, история буфера обмена, запись журнала, раскладка по
  умолчанию, время жизни состояния, исключения;
  «Сохранить» пишет `config.txt` и применяет настройки на лету
  (журнал — после перезапуска).
- **Раскладка под активное окно** — память раскладок по окнам с восстановлением при переключении (Alt+Tab, Cmd+Tab).
- **Раскладка по умолчанию** для новых окон: `en`, `ru` или `keep` (не трогать).
- **Запоминание ручных переключений** — смена раскладки вручную сохраняется для окна.
- **Список исключений** — приложения (терминал, менеджеры паролей и т.п.), где программа не вмешивается.
- **«Протухание» состояния** — сохранённая раскладка окна устаревает через настраиваемое время.
- **Автопереключение по печати** (Punto-стиль, включено по умолчанию) — частотные
  словари (FrequencyWords/OpenSubtitles, top-200k на язык) + 3-граммная
  fallback-модель для слов вне словаря; гистерезис — не более одного
  автопереключения на слово; ретро-фикс отключается (`retro_fix = false`).
- **Хоткей конвертации** — по умолчанию тап `Option`
  (нажать и чисто отпустить); настраивается (`f13`, `ctrl+shift+f13`, `cmd+t`,
  `ctrl+shift`, ...); работает и при выключенном автопереключении.
- **Спеллчек-подсказки** — по завершении слова пробелом, если слово
  отсутствует в словаре, у курсора мыши появляется попап с вариантами
  исправления: опечатки (расстояние Дамерау-Левенштейна 1) и конвертация
  раскладки; клик мышью или цифры `1–9` применяют вариант, `Esc` — закрывает.
  Попап не крадёт фокус — печать не прерывается.
- **История буфера обмена** — копирования сохраняются в
  `~/.config/smartswitcher/clipboard_history.txt` (по умолчанию 50 записей,
  вместе с временем копирования); в меню агента подменю «Буфер обмена»
  показывает последние записи со временем («ЧЧ:ММ», для прошлых дней —
  «ДД.ММ ЧЧ:ММ»; время — только для показа); клик возвращает текст записи
  в буфер и сразу вставляет в активное приложение.
  Копирования из приложений-исключений и промежуточные записи собственного
  конвейера конвертации в историю не попадают.
- **Горячая перезагрузка конфигурации** — `config.txt` перечитывается раз в 5 секунд, перезапуск не нужен.
- **Корректная остановка** по SIGINT/SIGTERM (в том числе из меню); агент без иконки в Dock.

## Требования

- **macOS** — для реального переключения раскладки.
  Разрешение: *Системные настройки → Конфиденциальность и безопасность → Доступность (Accessibility)*.
  Оно нужно и заголовкам окон, и режиму печати (CGEventTap). Без разрешения
  программа корректно деградирует: переключение — на уровне приложений,
  режим печати отключается с записью в журнал, приложение продолжает работать.
- Переключение использует только **включённые** источники ввода
  (*Системные настройки → Клавиатура → Источники ввода*).
- На других ОС собирается и запускается демонстрационный режим на эмуляторе
  системы (`src/stub.rs`) — для проверки логики и тестов.

## Сборка и запуск

```sh
make build          # debug-сборка
make run            # сборка и запуск debug-версии
make release        # релизная сборка
```

Конфигурация и журнал живут в одном месте — `~/.config/smartswitcher/`
(или `$XDG_CONFIG_HOME/smartswitcher`) — независимо от того, откуда запущен
бинарник (debug, release, `.app`-бандл). Программа при первом запуске создаёт
конфиг самостоятельно; `config.txt` из старого «портативного» расположения
(рядом с бинарником) переносится автоматически один раз.

Словари режима печати уже в репозитории (`assets/lang/*.tsv`) и встроены в
бинарник; перегенерация: `make dicts` (нужна сеть).

Справка по ключам и путям: `./target/release/smartswitcher --help`.
Ключи: `--list-layouts` (включённые раскладки и их классификацию),
`--no-ui` (без иконки в меню-баре).

## Конфигурация

Файл: `~/.config/smartswitcher/config.txt` (при заданном `XDG_CONFIG_HOME` —
`$XDG_CONFIG_HOME/smartswitcher/config.txt`). Создаётся автоматически при
первом запуске (эталон значений по умолчанию — `assets/config.txt`).
Формат — `ключ = значение`, строки с `#` — комментарии.

```text
# Автоматическая коррекция раскладки под активное окно
auto_correct = true

# Раскладка по умолчанию для новых окон: en | ru | keep
default_layout = keep

# Секунды, после которых сохранённое состояние окна считается неактуальным
idle_pause_seconds = 60

# Приложения, для которых коррекция НЕ применяется (через запятую)
exclude_apps = 1Password,KeePassXC

# Автопереключение раскладки по ходу печати (Punto-стиль).
# Фича перехватывает поток клавиатуры; при проблемах выключите здесь.
typing_detect = true

# Минимальная длина префикса слова для начала скоринга
min_prefix_chars = 3

# Порог уверенности для автопереключения («во сколько раз»)
switch_threshold = 100.0

# Исправлять уже набранный «неправильный» префикс слова (backspace × k + ввод)
retro_fix = true

# Горячая клавиша конвертации последнего слова или выделенного текста: option | f13 | ctrl+shift+f13 | cmd+t ...
# «option» — тап модификатора: срабатывает на отпускании, если между нажатием
# и отпусканием не было других клавиш.
convert_hotkey = option

# Спеллчек-подсказки: после разделителя показывать попап с вариантами
# исправления, если слово похоже на опечатку (клик или цифры 1-9)
spell_suggest = true

# Минимальная длина слова для спеллчек-подсказок
spell_min_chars = 4

# Сколько вариантов исправления показывать (1..9)
spell_max_suggestions = 5

# История буфера обмена: сохранять копирования и показывать в меню
clipboard_history = true

# Сколько последних копирований держать в истории
clipboard_history_size = 50

# Писать журнал в файл (применяется при старте программы)
write_log = false
```

| Параметр | По умолчанию | Описание |
|---|---|---|
| `auto_correct` | `true` | Включение/выключение автокоррекции |
| `default_layout` | `keep` | Раскладка новых окон: `en`, `ru` или `keep` |
| `idle_pause_seconds` | `60` | Время жизни сохранённой раскладки окна |
| `exclude_apps` | *(пусто)* | Имена приложений-исключений через запятую |
| `typing_detect` | `true` | Автопереключение по ходу печати |
| `min_prefix_chars` | `3` | Минимальный префикс для скоринга |
| `switch_threshold` | `100.0` | Порог уверенности (во «сколько раз») |
| `retro_fix` | `true` | Исправлять набранный префикс слова |
| `convert_hotkey` | `option` | Хоткей конвертации последнего слова или выделенного текста |
| `spell_suggest` | `true` | Спеллчек-подсказки (попап у курсора мыши) |
| `spell_min_chars` | `4` | Минимальная длина слова для подсказок |
| `spell_max_suggestions` | `5` | Сколько вариантов показывать (1..9) |
| `clipboard_history` | `true` | Сохранять копирования и показывать историю в меню |
| `clipboard_history_size` | `50` | Сколько последних копирований хранить |
| `write_log` | `false` | Писать журнал в файл (применяется при старте) |

## Режим печати

Как работает автопереключение:

1. На main run loop вешается активный `CGEventTap` (keyDown + flagsChanged).
   События с модификаторами (кроме Shift/Caps) не анализируются и не
   изменяются — системные хоткеи не ломаются; ввод не подавляется.
2. Каждая клавиша переводится в пару «символ в EN / символ в RU»
   (runtime-таблицы из `UCKeyTranslate` включённых раскладок; fallback —
   статические US QWERTY/ЙЦУКЕН). Словом считается клавиша, дающая букву
   хоть в одной раскладке: RU-слова с `х/ж/б/ю/ъ/ё` (в EN это `[ ; , . ]` и
   `` ` ``) тоже исправляются из EN-раскладки — пунктуация в гипотезе
   чужой раскладки топит её скоринг, ложных переключений порог не пускает.
3. После каждого символа (начиная с `min_prefix_chars`) сравниваются гипотезы:
   `log(max_freq_prefix)` по частотному словарю, при отсутствии покрытия —
   3-граммная модель. При перевесе «чужой» раскладки на `switch_threshold`
   и более — переключение (+ретро-фикс префикса). Не более одного
   автопереключения на слово (гистерезис); ручная смена раскладки и пауза
   >3 с сбрасывают слово.
4. Свои инжектированные события различаются по `kCGEventSourceStateID`
   (аппаратные = 1, наши посты = 0) — циклов не возникает.
5. Secure Input (поля паролей) и отключение тапа системой обрабатываются
   молчаливой деградацией: тап ре-включается (watchdog + в колбэке), ничего
   не переключается.

Хоткей конвертации: тап модификатора (по умолчанию `Option`) — нажатие
«взводит» триггер, любая другая клавиша или добавочный модификатор гасит его,
чистое отпускание конвертирует последнее слово (backspace × k + ввод) и
переключает раскладку. Вариант с клавишей (`f13`, `cmd+t`, ...) срабатывает по
нажатию с точным набором модификаторов. Работает независимо от
`typing_detect`. Символ, оборвавший слово (разделитель или цифра/пунктуация),
стирается и вводится обратно как был; после Backspace и клавиш, двигающих
курсор (стрелки), «последнее слово» считается недействительным — конвертация
не выполняется, чтобы не править текст в чужом месте.

Спеллчек-подсказки (подробно):

1. По разделителю (пробел) зафиксированное слово проверяется по словарю
   своего языка: словарное слово ошибкой не считается.
2. Для неизвестного слова собираются варианты: словарные слова на
   расстоянии Дамерау-Левенштейна 1 (замена/вставка/удаление/транспозиция)
   и конвертация тех же клавиш в другую раскладку (если она словарная).
   Поиск — генерация edit-1 вариантов + бинарный поиск, микросекунды на
   слово; ранжирование по частоте, регистр исходного слова переносится.
3. Позиция попапа — у указателя мыши (чуть правее-ниже курсора) через
    CoreGraphics (`CGEventGetLocation` + геометрия дисплеев). Привязка к
    курсору, а не к каретке, работает во всех приложениях — терминалах,
    играх, Java — и корректна на нескольких мониторах (флип координат по
    главному дисплею, кламп в пределы дисплея с курсором).
4. Попап — `NSPanel` (borderless + nonactivating): фокус не крадёт.
   Клик по строке или цифра `1–9` применяет вариант (backspace × k+1 и
   ввод исправления; вариант-конвертация дополнительно переключает
   раскладку), `Esc` закрывает, любая другая клавиша закрывает и
   пропускается в приложение. Автозакрытие: 8 с таймаут, смена приложения,
   приложение из исключений.
5. Слова после автопереключения/ретро-фикса подсказками не сопровождаются.

Словари: FrequencyWords (OpenSubtitles), top-200 000 слов на язык, готовятся
`make dicts`; встраиваются в бинарник (`include_bytes!`), при старте грузятся в
фоновом потоке (release ~0.2 с, debug ~2.5 с) и не блокируют меню. Ё-слова
хранятся как есть; данные отделены от логики — архитектура допускает другие
пары языков.

Приватность: набранные слова не пишутся в журнал на уровне info
(только debug/trace).

Известные ограничения:

- Автокомплит полей (Google Docs, IDE) может конфликтовать с ретро-фиксом →
  `retro_fix = false`.
- Отдельные приложения (игры, RDP) могут игнорировать постед-события —
  работает fallback «только переключение» (`retro_fix = false`).
- Короткие EN-аббревиатуры, случайно совпадающие с частым русским префиксом
  (например `jdk` → `овл...`), могут переключиться — поправимо порогом
  `switch_threshold`.
- Спеллчек-подсказки: словарь топ-200k не знает редких словоформ и имён —
  возможны ложные попапы (закрываются любой клавишей); попап появляется у
  курсора мыши, а не у набираемого слова — курсор в этот момент может быть
  в другом месте экрана.

### Ручная проверка

Быстрый смоук без клавиатуры (постинг «аппаратноподобных» событий):

```sh
make run                                    # агент (в другом окне — ./target/debug/smartswitcher)
cargo run --example smoke_keys -- --keys the          # «the» в RU -> переключение на EN (+фикс)
cargo run --example smoke_keys -- --keys ghb          # «ghb» в EN -> переключение на RU (+фикс)
cargo run --example smoke_keys -- --keys the --tap-option  # затем тап Option -> конвертация слова
cargo run --example smoke_keys -- --layout-only       # показать текущую раскладку
```

Чеклист «живой» проверки: в TextEdit/браузере «ghbdtn» превращается в
«привет» без следа латиницы; «c[tfv» превращается в «схема» (клавиша `[` —
буква «х» в RU); Cmd+C/Cmd+V не затрагиваются; поле пароля
(Secure Input) не затрагивается; приложение из `exclude_apps` не
затрагивается; тап Option конвертирует последнее слово («ghb1» → «при1»:
цифра сохраняется); опечатка вида
«превет » (с пробелом) даёт попап с «1 привет» — цифра/клик применяют,
Esc закрывает; повторный запуск и остановка по сигналам не сломаны.

## Журнал

По умолчанию журнал **не пишется**. Включается ключом `write_log = true`
в `config.txt` (или галочкой в настройках — применится после перезапуска).
Логи пишутся в `~/.config/smartswitcher/smartswitcher.log` (тот же каталог,
что и `config.txt`), уровень `Info`; если файл создать нельзя — вывод в stderr.

## Как это работает

Основной цикл опрашивает активное окно каждые 200 мс:

1. Приложение в списке исключений → не трогаем.
2. Раскладка сменилась вручную (окно то же) → запоминаем новое состояние.
3. Активным стало другое окно → восстанавливаем его сохранённую раскладку,
   если она «свежая»; иначе применяем раскладку по умолчанию.

В headless-режиме (`--no-ui`) цикл работает на `CFRunLoop` + таймере (на том же
main run loop живёт event tap режима печати); в UI-режиме — на `NSTimer`
внутри `[NSApp run]`. В обоих режимах конфиг перечитывается раз в 5 с.

Доступ к ОС изолирован за трейтом `System`, поэтому ядро логики
(`src/engine.rs`, `src/predictor.rs` и др.) платформо-независимо и покрыто
unit-тестами на заглушке `StubSystem` и встроенных словарях.

На macOS:

- активное приложение — `NSWorkspace.frontmostApplication`;
- раскладка — Carbon TIS (`Text Input Source`): определение и принудительный
  выбор EN/RU из числа включённых источников ввода. Язык источника
  определяется **по скрипту символов, которые он печатает** (UCKeyTranslate):
  любая латинская раскладка — канадская, US-International, Dvorak — это EN,
  любая кириллическая — RU; фолбек — по ID (`...us`, `english`, `russian`,
  `canad`, ...), методы ввода (CJK) не трогаются;
- заголовок окна — Accessibility API через небольшой C-мост
  `assets/ax_bridge.c` (собирается `build.rs`), с таймаутом 0.25 с;
- режим печати — `CGEventTap`/`CGEventPost` (CoreGraphics) и
  `UCKeyTranslate` (HIToolbox).

## Установка и автозапуск

```sh
make cert          # ОДИН РАЗ: self-signed сертификат подписи (см. ниже)
make bundle        # релиз + самостоятельный Smartswitcher.app (в build/)
make install       # установка в /Applications
make reset-tcc     # сброс устаревшей записи «Доступность» (после миграции)
make run-bundle    # запуск установленного/локального бандла
make stop-bundle   # остановка агента
make uninstall     # удаление из /Applications
```

### Разрешение «Доступность» и пересборки

TCC хранит разрешение по кодовой подписи приложения:

- **ad-hoc-подпись** (без `make cert`) меняется при каждой пересборке —
  macOS считает бандл «другим» приложением, и галочку в «Конфиденциальность
  и безопасность → Доступность» приходится выдавать заново (иногда ещё
  и перезагружаться, пока tccd не заметит новую подпись);
- **self-signed сертификат** (`make cert`, одноразово) даёт стабильную
  подпись: разрешение выдаётся один раз после первого `make install`,
  а дальнейшие пересборки его сохраняют.

После перехода с ad-hoc на сертификат сбросьте старую запись
(`make reset-tcc` или вручную удалите приложение из списка «Доступность»),
затем выдайте разрешение заново — это последний раз.

Автозапуск через launchd — пример `examples/com.smartswitcher.agent.plist`.

## Структура проекта

```
├── build.rs                        # Сборка C-моста к Accessibility API, линковка системных фреймворков
├── assets/ax_bridge.c              # Мост к macOS Accessibility API (заголовок фокусного окна)
├── assets/config.txt               # Эталон дефолтного конфига (для теста синхронности с Config::default)
├── assets/lang/{en,ru}.tsv         # Частотные словари (make dicts), встраиваются в бинарник
├── tools/dict/prepare.py           # Скачивание/подготовка словарей FrequencyWords (make dicts)
├── examples/spike_tap.rs           # Спайк: проверка event tap и дискриминации своих событий
├── examples/smoke_keys.rs          # Ручная проверка режима печати (постинг «аппаратных» клавиш)
├── examples/com.smartswitcher.agent.plist  # Пример автозапуска через launchd
└── src/
    ├── main.rs                     # Точка входа, сигналы, логирование, headless/UI запуск
    ├── engine.rs                   # Платформо-независимое ядро: Layout, трейт System, Switcher + тесты
    ├── config.rs                   # Парсер и модель конфигурации + тесты
    ├── clipboard_history.rs        # История буфера обмена: память + файл + тесты
    ├── dict.rs                     # Частотный словарь: точный и префиксный поиск (RMQ) + тесты
    ├── ngram.rs                    # 3-граммная модель языка + тесты
    ├── keymap.rs                   # Статические таблицы keycode → символ (US/ЙЦУКЕН) + тесты
    ├── predictor.rs                # Стейт-машина слова, Decision, convert_last_word + тесты
    ├── spell.rs                    # Спеллчек: edit-1 кандидаты, layout-вариант + тесты
    ├── stub.rs                     # Заглушка System (демо-режим и unit-тесты)
    └── macos/
        ├── ffi.rs                  # Обёртки Carbon TIS / CoreFoundation / CoreGraphics
        ├── system.rs               # Реализация System для macOS
        ├── keymap.rs               # Runtime keymap через UCKeyTranslate
        ├── event_tap.rs            # Режим печати: тап, предиктор, ретро-фикс, хоткеи, подсказки
        ├── suggest_panel.rs        # Попап спеллчек-подсказок (NSPanel без активации)
        ├── headless.rs             # Headless-цикл на CFRunLoop
        └── ui.rs                   # Меню-бар: статус-айтем, меню, окно настроек
```

## Тесты

```sh
cargo test          # 98 unit-тестов; macOS и сеть не нужны
make check          # fmt --check + clippy -D warnings + тесты
```

Покрытие: применение раскладки по умолчанию, запоминание ручных переключений,
исключения (включая кириллические имена без учёта регистра), режим `keep`;
сценарии режима печати («ghbdtn» → переключение на 3-м символе, слова с
клавишами-«пунктуациями» чужой раскладки («схема» из EN), коллизии с
порогом, n-граммный fallback, сбросы по цифре/паузе/ручной смене, запрет
конвертации после Backspace/стрелок, сохранение цифры-разделителя при
хоткее, конвертация последнего слова в обе стороны, тап модификатора,
кейсы на реальных словарях); парсер конфигурации (мусорные bool-значения
не выключают фичи) и синхронность `assets/config.txt` с дефолтами; история
буфера обмена (дедупликация, ёмкость, экранирование многострочных записей,
save/load, метки пунктов меню).

Калибровка порогов на реальных словарях:
`cargo test -- --ignored print_real_dict_margins --nocapture`.
