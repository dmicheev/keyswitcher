# keyswitcher (smartswitcher)

Smart Switcher для macOS (на Rust): автоматическая смена раскладки клавиатуры (EN/RU) под активным окном.

Программа запоминает, какая раскладка использовалась в каждом окне, и восстанавливает её при возврате в окно. Новым окнам применяется раскладка по умолчанию. Ручное переключение пользователем не «борется» с программой — оно запоминается для текущего окна.

## Возможности

- **Иконка в меню-баре** — показывают текущую раскладку (EN/RU), клик открывает меню:
  быстрое переключение раскладки, настройки, открытие config.txt и журнала, выход.
- **Диалог настроек** — автокоррекция, раскладка по умолчанию, время жизни состояния
  и список исключений; «Сохранить» пишет `config.txt` и применяет настройки на лету.
- **Раскладка под активное окно** — память раскладок по окнам с восстановлением при переключении (Alt+Tab, Cmd+Tab).
- **Раскладка по умолчанию** для новых окон: `en`, `ru` или `keep` (не трогать).
- **Запоминание ручных переключений** — если вы сменили раскладку в окне вручную, она сохранится для этого окна.
- **Список исключений** — приложения (терминал, менеджеры паролей и т.п.), где программа не вмешивается.
- **«Протухание» состояния** — сохранённая раскладка окна считается неактуальной спустя настраиваемое время.
- **Горячая перезагрузка конфигурации** — файл конфига перечитывается раз в 5 секунд, перезапуск не нужен.
- **Корректная остановка** по SIGINT/SIGTERM (в том числе из меню).
- Работает как агент без иконки в Dock.

## Требования

- **macOS** — для реального переключения раскладки.
  Требуемое разрешение: *Системные настройки → Конфиденциальность и безопасность → Доступность (Accessibility)*.
  Нужны заголовки окон; без разрешения программа корректно деградирует до режима «раскладка на уровне приложения».
- На других ОС собирается и запускается в демонстрационном режиме на эмуляторе системы (`src/stub.rs`) — удобно для проверки логики и тестов.
## Сборка и запуск

```sh
cargo build --release
./target/release/smartswitcher
```

Справка по ключам и путям:

```sh
./target/release/smartswitcher --help
```

Ключи: `--list-layouts` (показать включённые раскладки и их классификацию),
`--no-ui` (запуск без иконки в меню-баре, «головой» поллинг — как раньше).

Переключение использует только **включённые** источники ввода
(*Системные настройки → Клавиатура → Источники ввода*).

## Конфигурация

Файл: `config.txt` **рядом с исполняемым файлом** программы (портативный режим) — например, `target/release/config.txt`; в `.app`-бандле — `Smartswitcher.app/Contents/MacOS/config.txt`. Файл не создаётся автоматически; при отсутствии используются значения по умолчанию. Формат — `ключ = значение`, строки с `#` — комментарии.

```text
# Автоматическая коррекция раскладки под активным окном
auto_correct = true

# Раскладка по умолчанию для новых окон: en | ru | keep
default_layout = keep

# Секунды, после которых сохранённое состояние окна считается неактуальным
idle_pause_seconds = 60

# Приложения, для которых коррекция НЕ применяется (через запятую)
exclude_apps = 1Password,KeePassXC
```

| Параметр | По умолчанию | Описание |
|---|---|---|
| `auto_correct` | `true` | Включение/выключение автокоррекции |
| `default_layout` | `keep` | Раскладка новых окон: `en`, `ru` или `keep` |
| `idle_pause_seconds` | `60` | Время жизни сохранённой раскладки окна |
| `exclude_apps` | *(пусто)* | Имена приложений-исключений через запятую |

## Журнал

Логи пишутся в `smartswitcher.log` рядом с исполняемым файлом (тот же каталог, что и `config.txt`), уровень `Info`. Если файл создать нельзя — вывод в stderr.

## Как это работает

Основной цикл опрашивает активное окно каждые 200 мс и на каждом шаге решает, что делать:

1. Приложение в списке исключений → не трогаем.
2. Раскладка сменилась вручную (окно то же) → запоминаем новое состояние.
3. Активным стало другое окно → восстанавливаем его сохранённую раскладку, если она ещё «свежая»; иначе применяем раскладку по умолчанию.

Доступ к ОС изолирован за трейтом `System`, поэтому ядро логики (`src/engine.rs`) платформо-независимо и покрыто unit-тестами на заглушке `StubSystem`.

На macOS:

- активное приложение — `NSWorkspace.frontmostApplication`;
- раскладка — Carbon TIS (`Text Input Source`): определение и принудительный выбор EN/RU из числа установленных в системе источников ввода;
- заголовок окна — Accessibility API через небольшой C-мост `assets/ax_bridge.c` (собирается `build.rs`), с таймаутом 0.25 с на случай «глухих» приложений.

## Структура проекта

```
├── build.rs                        # Сборка C-моста к Accessibility API, линковка системных фреймворков
├── assets/ax_bridge.c              # Мост к macOS Accessibility API (заголовок фокусного окна)
├── examples/com.smartswitcher.agent.plist  # Пример автозапуска через launchd
└── src/
    ├── main.rs                     # Точка входа, основной цикл, сигналы, логирование
    ├── engine.rs                   # Платформо-независимое ядро: Layout, трейт System, Switcher + тесты
    ├── config.rs                   # Парсер и модель конфигурации + тесты
    ├── stub.rs                     # Заглушка System (демо-режим и unit-тесты)
    └── macos/
        ├── ffi.rs                  # Обёртки над Carbon TIS / CoreFoundation
        ├── system.rs               # Реализация System для macOS
        └── ui.rs                   # Меню-бар: статус-айтем, меню, окно настроек
```

## Тесты

```sh
cargo test
```

Тесты покрывают логику ядра: применение раскладки по умолчанию новому окну, запоминание ручных переключений с восстановлением при возврате, исключения, режим `keep`.
