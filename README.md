# keyswitcher (smartswitcher)

Smart Switcher для macOS (на Rust): автоматическая смена раскладки клавиатуры (EN/RU) под активное окно + автопереключение по ходу печати (Punto-стиль).

Программа запоминает, какая раскладка использовалась в каждом окне, и восстанавливает её при возврате в окно. Новым окнам применяется раскладка по умолчанию. Ручное переключение пользователем не «борется» с программой — оно запоминается для текущего окна.

Дополнительно доступен режим печати: во время набора по потоку физических клавиш программа определяет, на каком языке вы собираетесь набрать слово, и при уверенном определении **переключает раскладку и исправляет уже набранный «неправильный» префикс** (backspace × k + ввод правильных символов) — как Punto Switcher. Отдельная горячая клавиша конвертирует последнее слово в другую раскладку.

## Возможности

- **Иконка в меню-баре** — показывают текущую раскладку (EN/RU), клик открывает меню:
  быстрое переключение раскладки, настройки, открытие config.txt и журнала, выход.
- **Диалог настроек** — автокоррекция, автопереключение по печати, ретро-фикс,
  раскладка по умолчанию, время жизни состояния и список исключений;
  «Сохранить» пишет `config.txt` и применяет настройки на лету.
- **Раскладка под активное окно** — память раскладок по окнам с восстановлением при переключении (Alt+Tab, Cmd+Tab).
- **Раскладка по умолчанию** для новых окон: `en`, `ru` или `keep` (не трогать).
- **Запоминание ручных переключений** — если вы сменили раскладку в окне вручную, она сохранится для этого окна.
- **Список исключений** — приложения (терминал, менеджеры паролей и т.п.), где программа не вмешивается.
- **«Протухание» состояния** — сохранённая раскладка окна считается неактуальной спустя настраиваемое время.
- **Автопереключение по печати** (Punto-стиль) — частотные словари (FrequencyWords/OpenSubtitles, top-200k на язык)
  + 3-граммная fallback-модель для слов вне словаря; гистерезис — не более одного
  автопереключения на слово; ретро-фикс отключается (`retro_fix = false`).
- **Хоткей конвертации последнего слова** — по умолчанию тап `Option`
  (нажать и чисто отпустить), настраивается (`f13`, `ctrl+shift+f13`, `cmd+t`,
  `ctrl+shift`...); работает и при выключенном автопереключении.
- **Горячая перезагрузка конфигурации** — файл конфига перечитывается раз в 5 секунд, перезапуск не нужен.
- **Корректная остановка** по SIGINT/SIGTERM (в том числе из меню).
- Работает как агент без иконки в Dock.

## Требования

- **macOS** — для реального переключения раскладки.
  Требуемое разрешение: *Системные настройки → Конфиденциальность и безопасность → Доступность (Accessibility)*.
  Нужны заголовки окон; без разрешения программа корректно деградирует до режима «раскладка на уровне приложения».
  Для режима печати используется то же разрешение (CGEventTap): без него функция
  выключается с записью в журнал, остальное приложение работает.
- На других ОС собирается и запускается в демонстрационном режиме на эмуляторе системы (`src/stub.rs`) — удобно для проверки логики и тестов.
## Сборка и запуск

```sh
make build          # debug + config.txt в target/debug (если ещё нет)
make run            # сборка и запуск debug-версии
```

`make build` / `make release` копируют дефолтный конфиг `assets/config.txt`
в каталог сборки, если `config.txt` там отсутствует (полная пересборка/cargo
clean стирает `target/` целиком); существующий конфиг не затирается.
Отдельно: `make config` — создать дефолтные конфиги в `target/{debug,release}`.

Словари режима печати уже встроены в репозиторий (`assets/lang/*.tsv`);
перегенерировать: `make dicts` (нужна сеть).

Справка по ключам и путям:

```sh
./target/release/smartswitcher --help
```

Ключи: `--list-layouts` (показать включённые раскладки и их классификацию),
`--no-ui` (запуск без иконки в меню-баре, «головой» поллинг — как раньше).

Переключение использует только **включённые** источники ввода
(*Системные настройки → Клавиатура → Источники ввода*).

## Конфигурация

Файл: `config.txt` **рядом с исполняемым файлом** программы (портативный режим) — например, `target/debug/config.txt` / `target/release/config.txt`; в `.app`-бандле — `Smartswitcher.app/Contents/MacOS/config.txt`. Создаётся автоматически: при первом запуске программы и при `make build`/`make release` (эталон — `assets/config.txt`). Формат — `ключ = значение`, строки с `#` — комментарии.

```text
# Автоматическая коррекция раскладки под активное окно
auto_correct = true

# Раскладка по умолчанию для новых окон: en | ru | keep
default_layout = keep

# Секунды, после которых сохранённое состояние окна считается неактуальным
idle_pause_seconds = 60

# Приложения, для которых коррекция НЕ применяется (через запятую)
exclude_apps = 1Password,KeePassXC

# Автопереключение раскладки по ходу печати (Punto-стиль).
# Фича перехватывает поток клавиатуры; при проблемах выключите здесь.
typing_detect = true

# Минимальная длина префикса слова для начала скоринга
min_prefix_chars = 3

# Порог уверенности для автопереключения («во сколько раз»)
switch_threshold = 100.0

# Исправлять уже набранный «неправильный» префикс слова (backspace × k + ввод)
retro_fix = true

# Горячая клавиша конвертации последнего слова: option | f13 | ctrl+shift+f13 | cmd+t ...
# «option» — тап модификатора: срабатывает на отпускании, если между нажатием
# и отпусканием не было других клавиш.
convert_hotkey = option
```

| Параметр | По умолчанию | Описание |
|---|---|---|
| `auto_correct` | `true` | Включение/выключение автокоррекции |
| `default_layout` | `keep` | Раскладка новых окон: `en`, `ru` или `keep` |
| `idle_pause_seconds` | `60` | Время жизни сохранённой раскладки окна |
| `exclude_apps` | *(пусто)* | Имена приложений-исключений через запятую |
| `typing_detect` | `true` | Автопереключение по ходу печати |
| `min_prefix_chars` | `3` | Минимальный префикс для скоринга |
| `switch_threshold` | `100.0` | Порог уверенности (во «сколько раз») |
| `retro_fix` | `true` | Исправлять набранный префикс слова |
| `convert_hotkey` | `option` | Хоткей конвертации последнего слова |

## Режим печати (автопереключение по ходу набора)

Как это работает:

1. На main run loop вешается активный `CGEventTap` (keyDown + flagsChanged).
   События с модификаторами (кроме Shift) не анализируются и не изменяются —
   системные хоткеи не ломаются; ввод не подавляется.
2. Каждая клавиша переводится в пару «символ в EN / символ в RU»
   (runtime-таблицы из `UCKeyTranslate` включённых раскладок; fallback —
   статические US QWERTY/ЙЦУКЕН).
3. После каждого символа (начиная с `min_prefix_chars`) сравниваются гипотезы:
   `log(max_freq_prefix)` по частотному словарю, при отсутствии покрытия —
   3-граммная модель. При перевесе «чужой» раскладки на `switch_threshold`
   и более выполняется переключение (+ретро-фикс префикса). Не более одного
   автопереключения на слово (гистерезис).
4. Свои инжектированные события различаются по `kCGEventSourceStateID`
   (аппаратные = 1, наши посты = 0) — циклов не возникает.
5. Secure Input (поля паролей) и отключение тапа системой обрабатываются
   молчаливой деградацией: тап ре-включается, ничего не переключается.

Словари: FrequencyWords (OpenSubtitles), top-200 000 слов на язык, готовятся
`make dicts` (нужна сеть; результат в `assets/lang/*.tsv`, встраивается в
бинарник `include_bytes!`, загрузка при старте ~0.5–2.5 с). Ё-слова хранятся
как есть; данные отделены от логики — архитектура допускает другие пары языков.

Ручная проверка без клавиатуры: запустите агент и
`cargo run --example smoke_keys -- --keys the` — пример постит
«аппаратноподобные» нажатия (см. также `examples/spike_tap.rs`).

Известные ограничения:

- Автокомплит полей (Google Docs, IDE) может конфликтовать с ретро-фиксом →
  `retro_fix = false`.
- Отдельные приложения (игры, RDP) могут игнорировать постед-события —
  работает fallback «только переключение».
- Короткие EN-аббревиатуры, случайно совпадающие с частым русским префиксом
  (например `jdk` → `овл...`), могут переключиться — поправимо порогом
  `switch_threshold`.

## Журнал

Логи пишутся в `smartswitcher.log` рядом с исполняемым файлом (тот же каталог, что и `config.txt`), уровень `Info`. Если файл создать нельзя — вывод в stderr.

## Как это работает

Основной цикл опрашивает активное окно каждые 200 мс и на каждом шаге решает, что делать:

1. Приложение в списке исключений → не трогаем.
2. Раскладка сменилась вручную (окно то же) → запоминаем новое состояние.
3. Активным стало другое окно → восстанавливаем его сохранённую раскладку, если она ещё «свежая»; иначе применяем раскладку по умолчанию.

В headless-режиме (`--no-ui`) цикл работает на `CFRunLoop` + таймере (на том же
main run loop живёт event tap режима печати); в UI-режиме — на `NSTimer`
внутри `[NSApp run]`.

Доступ к ОС изолирован за трейтом `System`, поэтому ядро логики (`src/engine.rs`,
`src/predictor.rs` и др.) платформо-независимо и покрыто unit-тестами на
заглушке `StubSystem` и встроенных словарях.

На macOS:

- активное приложение — `NSWorkspace.frontmostApplication`;
- раскладка — Carbon TIS (`Text Input Source`): определение и принудительный выбор EN/RU из числа установленных в системе источников ввода;
- заголовок окна — Accessibility API через небольшой C-мост `assets/ax_bridge.c` (собирается `build.rs`), с таймаутом 0.25 с на случай «глухих» приложений;
- режим печати — `CGEventTap` + `CGEventPost` (CoreGraphics) и `UCKeyTranslate` (HIToolbox).

## Структура проекта

```
├── build.rs                        # Сборка C-моста к Accessibility API, линковка системных фреймворков
├── assets/ax_bridge.c              # Мост к macOS Accessibility API (заголовок фокусного окна)
├── assets/lang/{en,ru}.tsv         # Частотные словари (make dicts), встраиваются в бинарник
├── tools/dict/prepare.py           # Скачивание/подготовка словарей FrequencyWords (make dicts)
├── examples/spike_tap.rs           # Спайк: проверка event tap и дискриминации своих событий
├── examples/smoke_keys.rs          # Ручная проверка режима печати (постинг «аппаратных» клавиш)
├── examples/com.smartswitcher.agent.plist  # Пример автозапуска через launchd
└── src/
    ├── main.rs                     # Точка входа, сигналы, логирование, headless/UI запуск
    ├── engine.rs                   # Платформо-независимое ядро: Layout, трейт System, Switcher + тесты
    ├── config.rs                   # Парсер и модель конфигурации + тесты
    ├── dict.rs                     # Частотный словарь: точный и префиксный поиск (RMQ) + тесты
    ├── ngram.rs                    # 3-граммная модель языка + тесты
    ├── keymap.rs                   # Статические таблицы keycode → символ (US/ЙЦУКЕН) + тесты
    ├── predictor.rs                # Стейт-машина слова, Decision, convert_last_word + тесты
    ├── stub.rs                     # Заглушка System (демо-режим и unit-тесты)
    └── macos/
        ├── ffi.rs                  # Обёртки Carbon TIS / CoreFoundation / CoreGraphics
        ├── system.rs               # Реализация System для macOS
        ├── keymap.rs               # Runtime keymap через UCKeyTranslate
        ├── event_tap.rs            # Режим печати: тап, предиктор, ретро-фикс, хоткей
        ├── headless.rs             # Headless-цикл на CFRunLoop
        └── ui.rs                   # Меню-бар: статус-айтем, меню, окно настроек
```

## Тесты

```sh
cargo test
```

Тесты покрывают логику ядра: применение раскладки по умолчанию новому окну, запоминание ручных переключений с восстановлением при возврате, исключения, режим `keep`; сценарии режима печати («ghbdtn» → переключение на 3-м символе, коллизии с порогом, n-граммный fallback, сбросы по цифре/паузе/ручной смене, конвертация последнего слова в обе стороны, кейсы реальных словарей) и парсер конфигурации. Тесты не требуют macOS и сети.

Калибровка порогов на реальных словарях: `cargo test -- --ignored print_real_dict_margins --nocapture`.
