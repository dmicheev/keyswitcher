# SmartSwitcher — конфигурация (~/.config/smartswitcher/config.txt)
# Перечитывается на лету раз в 5 секунд, перезапуск не нужен.

# Раскладка по умолчанию для новых окон: en | ru | keep

# Приложения, для которых коррекция НЕ применяется (через запятую)
